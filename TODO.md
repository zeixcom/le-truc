- [x] LT-005: Unified format for form components — extensions, attribute-driven props, `internals` (ADR 0023 acceptance gate)
  **Skill:** le-truc-dev
  **Context:** The sanctioned subset cannot activate `defineComponent`'s third argument — `formAssociated()` / `formAssociatedCheckbox()` (which must lead the array and widen the factory context to `FormFactoryContext`, ADR 0019) and `observedAttributes([...])` — nor use `internals`/`relayValidity`, Parser-backed attribute-driven `expose()` props, or `defineMethod()` members. Form components (`form-textbox`) cannot be authored in `.tsrx` today. Spike first, record the format decision as ADR 0023 sub-design 8, then implement in `server/tsrx/`.
  **Decision (owner, sub-design 8):** `export const config = { formAssociated: true, observedAttributes: [...] }` — chosen over a `useExtensions([...])` setup hook (a directive that never executes; hands the formAssociated-first rule back to the author) and a module-level `export const extensions = [...]` verbatim slice (viable, but wider validation surface for no gain over the closed key space).
  **Changed:** `examples/form/textbox/form-textbox.tsrx` (fixture: config, Parser-expose `value`, `defineMethod` `clear`, `value={() => host.value}` mirror, `&{'validationMessage'}` managed lazy child); `server/tsrx/` — compiler (config validation TSRX009, Parser-expose/defineMethod ambients, lazy-`&` sigil with leading whitespace), analyze (host/internals as ambient context names + `ambientContext` plan, host-prop mirror → `bindProperty` dispatch, managed lazy source), emit-server (mirror renders from the root attribute expression, managed child renders empty, ambient runtime imports), emit-client (third argument with form variant leading, `FormAssociatedElement` type import, ambient destructure, re-anchored multi-line reindent), runtime (`as*`/`defineMethod` shims); tests: 4 server goldens + CSS byte-golden, client snapshot + convergence + emit-then-check, 5 compiler units, 6 TSRX009 cases. The generated client typechecks ONLY under the widened `FormFactoryContext` overload — `watch('validationMessage', …)` and `host.setCustomValidity` exist nowhere else.
  **Open for the full form migration:** `length`-style signals need an arg→DOM-site substitution harvest rule (fixture omits `length`); setup side-effect statements (`internals?.states.add('clearable')`) are still outside the setup subset; `@if` is unsupported (input/textarea variants unrepresentable); `asClampedInteger`/`asJSON` not yet recognized parser ambients; no `formAssociatedCheckbox` fixture yet.
