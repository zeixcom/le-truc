asBoolean(): Parser<boolean>

Defined in: src/parsers/boolean.ts:16

Parser that converts a boolean HTML attribute to an actual boolean.

Returns true when the attribute is present (value is not null) and its value is not the string 'false', compared case-insensitively ('FALSE', 'False', … also opt out). Returns false otherwise — matching standard HTML boolean attribute semantics while allowing explicit opt-out via attr="false", and also covering ARIA-style string-boolean attributes (e.g. aria-hidden="true"/"false"), which are conventionally case-insensitive.
