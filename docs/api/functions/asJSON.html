Function: asJSON()#

asJSON<T>(fallback): Parser<T>

Defined in: src/parsers/json.ts:18

Parse a string as a JSON serialized object with a fallback

Reserved words (__proto__, constructor, …, see RESERVED_WORDS) are dropped from the parsed result at every nesting level via a JSON.parse reviver, so a crafted payload can't plant an own __proto__/constructor property that later corrupts a host's prototype chain (defense-in-depth alongside the runtime guard in #initSignals).
