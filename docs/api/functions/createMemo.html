Function: createMemo()#

Call Signature#

createMemo<T>(fn, options): Memo<T>

Defined in: node_modules/@zeix/cause-effect/types/src/nodes/memo.d.ts:50

Creates a derived reactive computation that caches its result. The computation automatically tracks dependencies and recomputes when they change. Uses lazy evaluation - only computes when the value is accessed.

Type Parameters#
NameTypeDescription
TT extends objectThe type of value computed by the memo

Since#

Examples#

ts

const count = createState(0);
const doubled = createMemo(() => count.get() * 2);
console.log(doubled.get()); // 0
count.set(5);
