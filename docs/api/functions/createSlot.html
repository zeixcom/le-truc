Function: createSlot()#

createSlot<T>(initialSignal, options?): Slot<T>

Defined in: src/nodes/slot.ts

Creates a slot signal that delegates its value to a swappable backing signal.

A slot acts as a stable reactive source usable as a property descriptor via Object.defineProperty(target, key, slot). Subscribers link to the slot itself, so replacing the backing signal with replace() invalidates them without breaking existing edges. set() forwards to the current backing signal if it is writable; update() is absent — a slot is a forwarding layer, not a value owner.
