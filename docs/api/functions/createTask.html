Function: createTask()#

Call Signature#

createTask<T>(fn, options): Task<T>

Defined in: node_modules/@zeix/cause-effect/types/src/nodes/task.d.ts:68

Creates an asynchronous reactive computation (colorless async). The computation automatically tracks dependencies and re-executes when they change. Provides abort semantics - in-flight computations are aborted when dependencies change.

Type Parameters#
NameTypeDescription
TT extends objectThe type of value resolved by the task
Parameters#
NameTypeDescription
fn(prev, signal) => Promise<T>The async computation function that receives the previous value and an AbortSignal
optionsSignalOptions<T> & object & objectOptional configuration for the task
Returns#
TypeDescription
Task<T>A Task object with get(), isPending(), and abort() methods
Since#

0.18.0

Examples#

ts

const userId = createState(1);
const user = createTask(async (prev, signal) => {
  const response = await fetch(`/api/users/${userId.get()}`, { signal });
  return response.json();
});

// When userId changes, the previous fetch is aborted
userId.set(2);

ts

// Check pending state
if (user.isPending()) {
  console.log('Loading...');
}
