defineMethod<T>(fn): T & object

Defined in: src/types.ts:148

Brand a custom method-producer function with the METHOD_BRAND symbol.

Use this to wrap any side-effect initializer so isMethodProducer() can identify it explicitly rather than relying on the absence of a return value.
