A map of child component property names to the reactive values to inject into them. Passed as the second argument to pass(). Keys must be property names of the target component Q.

Prefer the read-only thunk (() => host.prop) and the mediated { get, set } descriptor forms. The property-key and bare-writable-signal forms are deprecated; they warn in DEV_MODE and will be removed in the next major.
