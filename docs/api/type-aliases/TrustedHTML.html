Structural shape of the DOM's TrustedHTML type (Trusted Types API). Declared locally because lib.dom.d.ts does not yet ship this type in every environment — structural typing means the real DOM TrustedHTML (e.g. from window.trustedTypes.createPolicy(...).createHTML(...), or a sanitizer configured with RETURN_TRUSTED_HTML: true) satisfies it.
