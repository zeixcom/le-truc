Variable: DEEP_EQUALITY#

const DEEP_EQUALITY: <T>(a, b) => boolean

Defined in: src/graph.ts

Deep structural equality check for plain objects and arrays. Use when a signal holds an object or array and you want to avoid unnecessary downstream propagation when the value re-evaluates to a structurally identical result.
