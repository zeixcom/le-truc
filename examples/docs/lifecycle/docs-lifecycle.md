### Docs Lifecycle

Interactive teaching component for the [Component Lifecycle](../components.html#the-component-lifecycle) guide. Connect and disconnect a real `docs-pulse` component and watch its factory, effect setup, and cleanup run — the log lines come from events the component itself dispatches.
