### Docs Reconcile

Interactive teaching component for the [Dynamic Lists](../lists.html#reconcile-the-dom) guide. A keyed list of Swiss towns drives `reconcile()`. Check a checkbox, then shuffle or reverse — checked state and the `created #n` stamp survive every reorder, because rows are moved, never recreated.
