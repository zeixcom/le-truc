### Module Blogarchive

A CSS-only archive of blog posts grouped by year, with each year in a collapsible `<details>`/`<summary>` — only the current year starts open. Each entry reuses `basic-blogmeta` to format its publication date. The server renders the grouped markup directly, so no JavaScript behavior is involved.
