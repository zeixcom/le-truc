### Module Cem List

A server-rendered catalog of custom-element declarations. Demonstrates Le Truc's HTML-first approach taken to its logical extreme: the `{% cem-list %}` Markdoc tag reads the repo's custom-elements-manifest (`custom-elements.json`, generated by `bun run build:cem` via the `@zeix/cem-plugin-le-truc` analyzer plugin) at docs-build time and transforms it directly into static `card-collapsible` + `module-tabgroup` markup — no client-side JSON fetching, templating, or rendering at all. The client only registers the `module-cem-list` tag name and gets the interactive disclosure/tab behavior for free from `card-collapsible` and `module-tabgroup`.

#### Descendant Elements

None — content is generated server-side by the `{% cem-list %}` Markdoc tag, one `card-collapsible` per custom-element declaration in the manifest, with tabs for whichever of Fields / Methods / Attributes / CSS Properties / CSS Parts / Slots are non-empty.
