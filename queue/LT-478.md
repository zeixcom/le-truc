**Area:** examples
**Changed:** module-codeblock composes `<ModuleScrollarea orientation="horizontal">` around its `<pre><code>`; the composed render wraps the passed markup in scrollarea's `<div data-children="module-codeblock">`, and `first('code')` verifies into the parent's own region (LT-472). The `pre`/`code` rules moved from top-level `module-codeblock pre`/`code` into the `@scope to (basic-button > *)` block as bare rules; no scrollarea limit was needed (LTC087 silent). Hand-authored codeblock markup now mirrors the composed render: the fixture `module-codeblock.html`, the docs fence schema `server/schema/fence.markdoc.ts` and the tab-panel fragment `server/templates/fragments.ts` carry the wrapper, pinned by tests. Computed styles of `pre`/`code` unchanged (Chromium probe); the bare rules tie with `_global.css` at (0,0,1) and win by page-first order (lowered) or scope (native).
**Review:** Approved (2026-10-08). The wrapper edits were needed: without them every docs code block lost enhancement. Follow-up LT-512 (owner: P6, track C2): the emitted `code` query excludes `module-scrollarea *` only because `mayMatchShape` counts scrollarea's `children` shape as a clash, which makes a compiler-internal marker a requirement for hand-authored markup.
